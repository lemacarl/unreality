Unit tests cover the contract against both stores (#13).

- `ActivitySource` protocol and `ActivitySample` / `FrontmostApp` types with a `FakeActivitySource`; `WorkspaceActivitySource` reads the frontmost app (NSWorkspace activation notifications) and its focused window title (Accessibility API, `AXObserver`; no polling) (#17).
- `AccessibilityTrust` protocol with `SystemAccessibilityTrust` (`AXIsProcessTrusted`; prompts only on explicit request) and `FakeAccessibilityTrust`; without Accessibility permission activity degrades to app-only samples (#17).
- `ActivityCoordinator`: stops the activity source while capture is paused, publishes Accessibility trust state (restarting the source when trust is granted), strips titles without trust, for processes without a bundle ID and for Unreality's own windows, and requires an `ActivitySampleFilter` (the seam for the privacy filter, #20) (#17).
- `CaptureStateStore.onChange(_:)` for synchronous, cancellable state-change handlers (#17).
- Privacy filter in `UnrealityCore` (#20): `PrivacyFilter`, the real `ActivitySampleFilter` for `ActivityCoordinator`, never allows the window titles of excluded apps, or of apps without a bundle ID, to be read. It drops excluded apps' samples (also app-only ones) and builds `FilteredEvent`s with the user's current rules; `PrivacyRules` is its pure, `Sendable` logic. Building an event drops excluded sites (domain and subdomains, compared percent-decoded, as lowercase punycode; invalid hosts fail closed), checks wrapped `blob:`/`view-source:`/`filesystem:` URLs by their inner URL, and drops browser-extension pages. It fails closed on URLs it cannot check, including host-less schemes other than `about:` and `data:`. URLs are redacted to `scheme://host[:port]/path` (query, fragment, credentials and `;` parameters dropped; optional host-only mode). `Blocklist` holds exact or `.*` prefix bundle-ID patterns and domains, with default exclusions for password managers, messaging and mail apps, and password-manager, messaging, webmail, banking and payment sites. The defaults are listed in docs/PRIVACY.md, and a test keeps that list in sync with the code. User entries extend the defaults. Unit tests prove excluded fixture activity never reaches the repository, the database or its files.
- Browser URL capture (#19): `BrowserURLProvider` protocol with `FakeBrowserURLProvider`, `KnownBrowser` (Safari, Chrome, Chromium, Arc, Brave, Edge; Firefox, other browsers and web apps as unsupported) and `BrowserURLReading`/`BrowserURLUnavailability`/`BrowserAutomationPermission` in `UnrealityCore`; `AppleEventBrowserURLProvider` in `UnrealityPlatform` reads the active tab's URL with Apple Events addressed to the front window by its unique ID. It checks Automation permission without prompting (cached per process; prompts only on explicit request), never reads Chrome-family incognito windows, reads only a window whose name matches the focused window's Accessibility title, stops sending to a browser that timed out until the next app switch, and handles denial as an unreadable URL. Tor Browser, Mullvad Browser, DuckDuckGo, Opera GX, Waterfox, Dia and Vivaldi are known but unsupported browsers (titles dropped). `ActivitySample` gains an optional `browserURL` (default `nil`, meaning "not a web sample"); `WorkspaceActivitySource` and `FakeActivitySource` take an optional provider and ask it only for known browsers after the title policy allowed the title. The app has an `NSAppleEventsUsageDescription` and the Apple Events entitlement.
- Opt-in browser integration test (`UNREALITY_BROWSER_TESTS=1`, or `=prompt` to request permission) (#19).

- Launch at login (#56): `LoginItemService` protocol, `LoginItemStatus`, `LoginItemError`, `FakeLoginItemService` and an observable `LaunchAtLoginModel` in `UnrealityCore`; `SMAppServiceLoginItemService` (`SMAppService.mainApp`) in `UnrealityPlatform`. The Settings window's General tab has an "Open Unreality at login" toggle, off by default; it never registers without the user turning it on, reads the state from macOS each time (not stored in settings), explains the `requiresApproval` state with a button that opens System Settings > General > Login Items, and shows registration errors. Unit tests use the fake.

### Changed
- `PrivacyFilter.filter(_:)` now applies the site check to samples' browser URLs (#19): excluded sites are dropped at capture, URLs are redacted (query, fragment, credentials and `;` parameters dropped) before samples leave the coordinator, a known browser's sample without a readable URL loses its title, and `about:`/`data:` pages lose their title. Browser-internal password, payment and wallet pages (`chrome://password-manager`, `edge://wallet`, `chrome://settings/passwords`, `edge://settings/personalinfo`, `about:logins`, ...) are dropped (`PrivacyDropReason.excludedBrowserPage`), URLs with a `\` before the query or fragment fail closed, and non-`http(s)` URLs with a host are stored as `scheme://host` instead of the scheme only. `evaluate`/`event` use the sample's URL; their `url` argument overrides it.
- `ActivityRepository.insert(_:)` now takes a `FilteredEvent`, so excluded or unredacted activity cannot be stored by construction. `ActivityEvent` is read-only (no longer persistable) and redacts its window title and URL (as does `ActivitySample`) in `description`, `debugDescription` and `dump`. GRDB `publicStatementArguments` is set off explicitly, with a test (#20).
- `CaptureStateStore` is now owned by an `AppModel` held by the app delegate instead of the SwiftUI `App` struct (#15).
